## 2024-03-16 - Accessibility pattern: ARIA labels on visual text '×'\n**Learning:** When using text characters like '×' or HTML entities like '&times;' inside an icon-only button without an aria-label, the button becomes inaccessible to screen readers. If we add aria-label, we must also add aria-hidden='true' to the visual text to prevent redundant announcements.\n**Action:** Always add aria-label to icon-only buttons. Always wrap visual icon text like '×' in <span aria-hidden="true">×</span> if an aria-label is present on the parent button.
