## 2024-05-24 - Accessible Icon-Only Close Buttons
**Learning:** For icon-only buttons using text characters like '×' or HTML entities like `&times;`, simply providing a `title` attribute is insufficient. The visual character will be redundantly announced or misread by screen readers, while the `title` attribute might not be reliably announced at all. However, if the text character is hidden with `aria-hidden="true"` but the `<button>` itself does not have an `aria-label`, the button becomes completely invisible to screen readers, causing a major accessibility regression.
**Action:** Always verify that icon-only `<button>`s have a descriptive `aria-label` (e.g., `aria-label="Close"`), and explicitly hide the visual icon/character text from screen readers by wrapping it in `<span aria-hidden="true">` or adding `aria-hidden="true"` to an SVG element.
