## 2024-05-24 - PowerShell Command Injection Prevention
**Vulnerability:** In `src/api/sandbox-routes.ts`, `performType` and `performKeypress` methods on Windows attempt to escape single quotes via `text.replace(/'/g, "''")` and pass the user input directly into a PowerShell script block string (`[System.Windows.Forms.SendKeys]::SendWait('${escaped}')`). This standard escaping is vulnerable to command injection via bypass techniques or mismatch in command parsing when passed via `execFileSync("powershell", ["-Command", ...])`.
**Learning:** When passing arbitrary user input to `powershell -Command` via Node's `execSync` or `execFileSync` on Windows, relying on string replacement (e.g. replacing `'` with `''`) within the command string is dangerous and easily bypassed.
**Prevention:** Instead of string interpolation with manual escaping, encode the user input as a Base64 string in Node (`Buffer.from(text).toString('base64')`) and decode it natively inside the PowerShell script block using `[System.Text.Encoding]::UTF8.GetString([System.Convert]::FromBase64String('${base64}'))`.
