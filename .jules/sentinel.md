## 2024-05-18 - PowerShell Command Injection via Single Quotes
**Vulnerability:** Command injection when passing arbitrary user input to `powershell -Command` via `execSync` or `execFileSync` on Windows. The previous code attempted to escape single quotes by duplicating them (`text.replace(/'/g, "''")`), but this can be bypassed or fail in certain complex PowerShell contexts.
**Learning:** Standard single-quote escaping is insufficient for completely securing arbitrary text sent to a PowerShell process spawned from Node.js, because the boundary between Node's shell spawning, the cmd.exe layer (if applicable), and PowerShell's parser is fragile.
**Prevention:** Never pass arbitrary text directly into a PowerShell command string. Instead, encode the user input as a Base64 string in Node (`Buffer.from(text).toString('base64')`) and decode it natively inside the PowerShell script block using `[System.Text.Encoding]::UTF8.GetString([System.Convert]::FromBase64String('${base64}'))`.
