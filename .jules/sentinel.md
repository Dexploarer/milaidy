## 2024-05-24 - PowerShell Command Injection via Single Quotes
**Vulnerability:** In `src/api/sandbox-routes.ts`, `performType`, `performKeypress`, and `playAudio` capability tools formatted arbitrary user inputs into PowerShell string commands executed via Node.js by merely escaping single quotes (e.g. `text.replace(/'/g, "''")`).
**Learning:** This is vulnerable because standard single-quote escaping in PowerShell scripts (`''`) doesn't fully guard against execution environment vulnerabilities and edge-case injection via malicious sequences when passed through child_process execution strings.
**Prevention:** Instead of string escaping, pass arbitrary variables safely into script blocks. When executing ad-hoc dynamically formatted PowerShell inline scripts on Windows in Node.js, wrap the unsanitized variable as base64 using `Buffer.from(text).toString('base64')` and natively decode it inside the script string with `[System.Text.Encoding]::UTF8.GetString([System.Convert]::FromBase64String('${base64}'))`.
