## 2024-04-21 - React useMemo Dependencies with Mutable State
**Learning:** When memoizing derived lists (like sorted conversation histories) in React, it is critical to ensure that the dependency array includes all references that might trigger an underlying re-sort. Here, wrapping the array spread and `.sort()` in `useMemo` with `[conversations]` as the dependency avoids triggering `Date` parsing and `O(n log n)` operations on every keystroke in a neighboring input field (e.g. `editingTitle`), which otherwise re-renders the whole component block.
**Action:** Always scan for inline `.sort()`, `.filter()`, or mapping over large/complex arrays within React components. If the component possesses local state updated rapidly by user interaction (like an active input field), wrap the expensive derivation in `useMemo` immediately.
