## 2024-04-11 - Optimize parseSegments fast path in MessageContent
**Learning:** `parseSegments` is called frequently (especially via `useMemo` for every visible message block in `MessageContent.tsx`). It runs multiple global regex operations (`[CONFIG:pluginId]` and fenced JSON code blocks) over the entire text body. Because 99%+ of standard chat messages are plain text, the regex matching adds unnecessary computational overhead for messages that do not contain config blocks or UI spec JSON.
**Action:** Implemented a quick string inclusion check (`!text.includes("[CONFIG:") && !text.includes("\`\`\`")`) before executing the regex expressions to provide an extremely fast bailout path, significantly reducing parsing time for standard messages without penalty for those that actually contain the markers.
